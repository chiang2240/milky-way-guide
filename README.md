### 🚀 快速開始

**第一次拍銀河？按這個順序讀：**

1. 先讀 [規劃指南](iphone_15_pro_milky_way_planning.md) — 確認什麼時候適合出門
2. 再讀 [地點指南](iphone_15_pro_milky_way_locations.md) — 決定去哪裡
3. 出發前讀 [參數設定手冊](iphone_15_pro_milky_way_guide.md) — 知道到現場怎麼設定
4. 現場參考 [構圖技巧](iphone_15_pro_milky_way_composition.md) — 拍出好照片

## 💬 現場遇到問題？

拍攝時如果遇到狀況，描述以下資訊即可獲得即時建議：

1. 你正在用哪顆鏡頭
2. 目前的 ISO 和快門設定
3. 你看到的問題（太暗、太亮、星點拖線、噪點多、模糊）
4. 環境狀況（月光、光害、雲量）
5. 你在用哪個 App（Halide / NightCap / 原生相機 / Vivo 專業模式）
