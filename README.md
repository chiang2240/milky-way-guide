## 💬 現場遇到問題？

點餐或用餐時如果遇到狀況，描述以下資訊即可獲得即時建議：

1. 你在哪個城市、哪個夜市或餐廳
2. 目前想吃什麼類型的料理（湯/乾/小吃/甜點）
3. 有無飲食限制（素食、過敏、辣度）
4. 預算範圍（銅板美食 <50 元 / 平價 <200 元 / 餐廳 >200 元）
